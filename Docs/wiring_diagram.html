General Notes

  1. MAX3232 모듈이 3.3V VCC를 지원하는지 확인한 뒤 전원을 연결한다. 5V 전용 모듈이면 레벨 변환이 필요하다.
  2. MAX3232의 TTL 측 핀(VCC/GND/RX/TX)에 RS-232 신호를 직접 연결하지 않는다.
  3. ESP32 GPIO를 플로터 RS-232 포트에 직접 연결하지 않는다 — 반드시 MAX3232를 경유한다.
  4. RS-232 측 배선은 교차 연결이다: MAX3232 TX → 플로터 RX, MAX3232 RX ← 플로터 TX.

PCB 제작 관련 안내

위 다이어그램은 연결 관계를 보여주는 배선도(개념 회로도)입니다. devicemart 같은 PCB 제조사 발주 페이지는 보통 실제 동판 패턴이 담긴 거버(Gerber) 파일과 드릴 파일을 요구하는데, 이 다이어그램만으로는 바로 주문할 수 없습니다.

devicemart의 custom=pcb 페이지는 브라우저 자동 열람으로는 정확한 파일 형식·규격(레이어 수, 최소 크기 등) 확인이 어려웠습니다 — 주문 전 고객센터 또는 실제 주문 화면에서 요구 사항을 직접 확인해 주세요.

실제 기판을 만들려면 이 핀맵을 기준으로 KiCad나 EasyEDA 같은 PCB 설계 툴에서 부품 풋프린트를 배치하고 배선(라우팅)한 뒤 거버 파일을 내보내는 단계가 필요합니다. 원하시면 다음 단계로 KiCad 프로젝트 구성(부품 선택, 풋프린트 매칭)을 같이 진행해드릴 수 있습니다.
